# 爭鮮儀表板 PoC v0.12a

2026/09/15 從指定 Google Sheets 重新讀取，各選四筆代表案件，共 16 件。

## 放到 BPM

將以下三個 HTML 放入 Herbert 提供的靜態網頁目錄，分別建立入口即可：

- tracker.html：一般案件追蹤。
- management.html：主管分類彙整、工作列表、Teams 聯繫示意及報告拖拉排序。
- meeting.html：內部會議；人工燈號初始皆待評估。

每個 HTML 已包含 CSS、JavaScript 與本次擷取資料，不需 Node.js、Java API、Google 金鑰或另外的資料檔。也可以直接雙擊開啟。本版非即時同步。若 BPM 的 CSP 阻擋行內 JavaScript，請維運提供規範後再改外部檔案打包；若 iframe 限制列印或開新視窗，需由維運確認其設定。

只包含 Frontend、Project、BPM、SAP；不含 DW 或 Infra 小組。品牌字與主色 #E95529 放在頂部，沒有 sidebar 或跨角色切換選單。

## 資料界線

- 小組、案件、負責人、狀態及 LOG 沿用本次工作表，並保留原始分頁／列號連結。原表 Status 在 L 欄，M 欄為 Note。
- 完成度依使用者要求補入 10%～100% 的虛擬展示值，用於截圖及排序，不代表實際進度；案件更新日期與人工燈號仍未提供。擷取日期不等於案件更新日期。
- LOG 節錄前三個非空行，完整 LOG 可從案件詳細內容查閱；保留日期原文，未將預排事項判定為完成。
- 主管版以「小組｜原表 Project/Catalog」分組，空白分類顯示未分類；不套用先前按列號指派的高階專案歸屬。彙整聯繫人為關聯案件負責人，非任命專案負責人。
- Teams 按鈕已保留，但原表無 Teams 帳號，現在顯示待設定，不會發送訊息。
- 會議燈號、風險及下一步的操作只存於瀏覽器，不回寫工作表。不同電腦不會同步。
- HTML 內含本次真實工作資料，請放到指定 BPM 展示空間。
