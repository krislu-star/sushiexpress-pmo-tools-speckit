# 預期清單：品牌官網 (brand)

> Phase 7 機會缺口的比對基準。格式與撰寫紀律見 [`_template.md`](./_template.md)。
> 對應 Phase 0 類型：**品牌官網**　·　最後更新：2026-08-13

**這類網站是什麼：** 以企業／品牌形象為主的官網，目的多為形象展示、建立信任、招募、投資人與媒體溝通、基本聯絡引導。轉換偏「軟」（認識品牌、留下聯絡、投遞履歷），通常**不直接在站上成交**。

**每項的 `現況證據` 與 `信心` 留白，稽核時填入。**

## 通常不需要（品牌官網多半不用做）

### 購物車／金流結帳
- 判斷依據：品牌官網是形象站、非電商，成交多在通路或另一個電商站。
- 說明：若真要販售，應評估獨立電商站或導流至既有通路，而非在形象站硬加購物車。

### 會員系統／登入
- 判斷依據：形象站少有需要登入才能看的內容或個人化服務。
- 說明：除非有經銷商專區、會員專屬內容等明確場景，否則徒增複雜度。

### 站內即時客服／聊天機器人
- 判斷依據：品牌官網互動量通常不足以支撐即時客服。
- 說明：以聯絡表單／Email 承接即可；客服量大再評估。
