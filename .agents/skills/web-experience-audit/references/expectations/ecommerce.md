# 預期清單：電商 (ecommerce)

> Phase 7 機會缺口的比對基準。格式與撰寫紀律見 [`_template.md`](./_template.md)。
> 對應 Phase 0 類型：**電商**　·　最後更新：2026-08-13

**這類網站是什麼：** 在站上直接販售商品、以「加入購物車 → 結帳 → 付款」為核心轉換的網站。核心任務是**讓訪客順利找到商品、信任、完成付款**，並降低結帳流程的每一個摩擦。

**每項的 `現況證據` 與 `信心` 留白，稽核時填入。**

## D. 轉換機制（電商的核心流程）

### 購物車 ＋ 結帳流程
- 分級：幾乎必備
- 判斷依據：這是電商轉換的主幹道，任何摩擦都直接反映在成交率。
- 影響：流程繁瑣、步驟過多是棄單主因。
- 建議：步驟精簡、進度可見、可隨時檢視購物車。

- 分級：幾乎必備

## 通常不需要（電商多半不用做）

### 大型內容知識庫／論壇
- 判斷依據：電商重心是商品與結帳，龐大內容社群多半分散資源。

### 複雜的預約排程系統
- 判斷依據：那是服務型的需求；商品電商以「下單即成交」為主。
- 說明：若有需預約的服務型商品（如體驗課），再局部評估。
