# 預期清單：服務型 (service)

> Phase 7 機會缺口的比對基準。格式與撰寫紀律見 [`_template.md`](./_template.md)。
> 對應 Phase 0 類型：**服務型**　·　最後更新：2026-08-13

**這類網站是什麼：** 提供服務、以「詢價／預約／諮詢／報名」為主要轉換的網站（顧問、診所、設計工作室、代辦、律師、B2B 專業服務）。核心任務是**把訪客推進到聯絡或預約**，並用專業與案例建立信任。

**每項的 `現況證據` 與 `信心` 留白，稽核時填入。**

## C. 信任與社會證明

### 案例／作品實績
- 分級：幾乎必備
- 判斷依據：服務無法「試用」，案例是訪客判斷專業度的主要依據。
- 影響：沒有案例＝沒有可信的品質證明，轉換率低。
- 建議：真實案例＋成果；案例量大時加分類／篩選。

## D. 轉換機制（服務型的核心）

### 主要轉換：詢價／預約／聯絡表單
- 分級：幾乎必備
- 判斷依據：服務型網站的存在目的就是產生詢問；這是主要轉換終點。
- 影響：轉換管道缺失或難用，等於整站流量無法變現。
- 建議：表單必填精簡（個人接洽者常無統編等欄位）；提供多種聯絡方式。

- 分級：幾乎必備

## 通常不需要（服務型多半不用做）

### 購物車／結帳流程
- 判斷依據：服務多為客製報價、非標準品，成交在詢價後線下完成。
- 說明：除非有標準化、可直接線上下單的套裝服務，否則不需電商結帳。

### 會員登入系統
- 判斷依據：服務型少有需要登入的個人化內容。
- 說明：除非有「客戶專屬進度／檔案區」等明確場景，否則徒增複雜度。

### 複雜產品比較表
- 判斷依據：那是電商／SaaS 的規格比較需求，服務型多以方案說明取代。
- 說明：服務差異用流程與案例呈現，比規格表更貼切。
