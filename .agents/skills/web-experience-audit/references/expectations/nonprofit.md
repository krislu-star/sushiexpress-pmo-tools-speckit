# 預期清單：非營利 (nonprofit)

> Phase 7 機會缺口的比對基準。格式與撰寫紀律見 [`_template.md`](./_template.md)。
> 對應 Phase 0 類型：**非營利**　·　最後更新：2026-08-13

**這類網站是什麼：** 基金會、協會、公益團體、社福機構的官網。核心任務是**傳達使命、募集資源（捐款／志工／參與）、揭露成果與財務以建立信任**。主要轉換多為捐款與參與，而非商業成交。

**每項的 `現況證據` 與 `信心` 留白，稽核時填入。**

## C. 信任與財務透明

- 分級：幾乎必備
- 判斷依據：財務透明是捐款信任的基礎，也常是法規與公信力要求。
- 影響：不透明會嚴重打擊大額與企業捐款意願。
- 建議：收支比例、財報下載、捐款流向說明。

## D. 轉換機制（非營利的核心：募資與參與）

### 捐款機制
- 分級：幾乎必備
- 判斷依據：捐款是非營利最主要的資源轉換，是網站的核心功能。
- 影響：捐款流程缺失或難用＝直接損失組織命脈。
- 建議：流程精簡、金額可選可自填、多元金流。
- 現況證據：
- 信心：

### 定期定額捐款
- 分級：幾乎必備
- 判斷依據：經常性收入是非營利財務穩定的關鍵，單次捐款每年都要重新獲取。
- 影響：只有單次捐款會讓組織收入不穩、獲取成本高。
- 建議：提供定期定額選項，需確認金流商支援。

- 信心：

- 影響：管道太少會流失偏好其他方式的捐款人。
- 建議：依捐款人結構配置；行動捐款可加 QR code。

## 通常不需要（非營利多半不用做）

### 完整購物車電商
- 判斷依據：非營利以捐款為主，除非有義賣商品，否則不需完整電商。
- 說明：少量義賣品可用簡易商品頁＋捐款金流承接，不必上完整電商系統。

### 會員專屬付費內容
- 判斷依據：非營利內容多以公開倡議為目的，付費牆與使命相悖。
- 說明：內容應盡量開放，資源以捐款而非付費牆取得。
