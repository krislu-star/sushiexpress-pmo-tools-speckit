# 預期清單：媒體內容 (media)

> Phase 7 機會缺口的比對基準。格式與撰寫紀律見 [`_template.md`](./_template.md)。
> 對應 Phase 0 類型：**媒體內容**　·　最後更新：2026-08-13

**這類網站是什麼：** 以內容為核心的網站（新聞、雜誌、部落格、知識平台、內容型社群）。核心任務是**讓讀者高效找到與消費內容、延長停留與回訪，並把流量變現**（廣告／訂閱／導購）。

**每項的 `現況證據` 與 `信心` 留白，稽核時填入。**

## 通常不需要（媒體內容多半不用做）

### 購物車／結帳
- 判斷依據：媒體以內容消費與廣告／訂閱變現為主，非商品販售。
- 說明：除非有周邊商城或導購電商，否則不需完整購物流程。

### 複雜表單／預約系統
- 判斷依據：那是服務型的轉換需求；媒體的互動集中在閱讀、訂閱、分享。
- 說明：以電子報訂閱與留言承接互動即可。
