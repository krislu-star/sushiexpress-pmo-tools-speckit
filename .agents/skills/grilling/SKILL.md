---
name: grilling
description: 用中文逐題追問使用者的計畫、決策或想法，直到需求與設計樹收斂。Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

用中文持續追問使用者，直到你們對需求、設計或決策達成共同理解。把整個討論整理成一棵 **design tree**：每個決策都會展開成依附於它的後續決策。

每次只問 **一個問題**。不要一次丟多題給使用者。

先找出目前 design tree 的 **frontier**：也就是前置條件都已經確定、現在可以問、且不需要猜測未知答案的決策點。若 frontier 有多個問題，選擇最能解除後續分支、風險最高或最能決定方向的那一題先問；等使用者回答後，再重新計算 design tree 與 frontier，繼續問下一題。

每題格式如下：

```
❓ **Q<n> - <問題標題>**

<問題內容。必要時可以提供選項，但仍然只問這一個決策。>

➡️ **建議答案**：<你的建議與理由>
```

使用者每回答一次，都會改變 design tree：已收斂的決策會把 frontier 往外推，並解鎖依賴它的下一批問題。依賴尚未回答問題的決策，必須留到後面再問，不可在同一題裡偷渡。

查 facts 是你的責任，不是使用者的責任。若問題需要 repo、檔案、工具或其他環境事實，先自己查；不要問使用者任何你能查到的東西。若需要較長時間探索，該探索結果就是尚未 settled 的前置條件；依賴它的問題先暫停，改問其他不依賴該探索結果的 frontier 問題。

使用者負責做決策；你負責把決策點問清楚、指出取捨，並提供建議答案。

當 frontier 清空、design tree 的每個分支都已走完、沒有任何默默假設的內容時，才算 grill 結束。在使用者確認已達成共同理解前，不要進入實作。
