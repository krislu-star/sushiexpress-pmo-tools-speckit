# 網站 + CMS 專案評估前置資料檢核表

> **用途**：新案評估啟動時，交給客戶窗口或業務填寫／蒐集。回收後連同原始文件一併餵給 AI（web-cms-quotation skill），產出規格釐清文件與報價。
> **原則**：缺漏項目不腦補，一律在規格釐清文件中標記為「待確認假設」。

---

## 使用方式

1. 複製本檔為 `{客戶名}-評估前置資料-{日期}.md`
2. 逐項勾選並填入資料來源（檔案路徑、URL 或「無／待取得」）
3. 完成度低於 60% 時，建議先安排需求訪談再進報價流程
4. 回收後與原始文件一起提供給 AI，並附上「缺漏項目清單」

## 完成度評估

- **蒐集完成項目數**：____ / 32（改版案）或 ____ / 24（全新案，略過第一節）
- **完成度**：____%
- **判定**：
  - ≥ 80% → 可直接進報價流程
  - 60–79% → 可報價，但規格釐清文件需列出待確認假設清單
