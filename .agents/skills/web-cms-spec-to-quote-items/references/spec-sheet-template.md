## 4A. 商業規則（橫切邏輯不變量）

> **這是規則的出生地。** 商業規則是跨頁面／跨模組的邏輯不變量（如「A 商品只能配 B 方案、不可與 C 同車」「依地區切換商品目錄／計價／金流」「付費前先登入」），**不對應單一交付項目**。若不在此獨立登記 BR-ID，只把它寫進某個 SCP 的描述句子裡，轉報價時極易被遺漏（沒有明顯歸屬頁的規則會變孤兒）。
>
> **填寫規則**：材料／訪談中每出現一條條件式、互斥、綁定、地區別或狀態流轉邏輯，就在此開一列給 BR-ID。**下游報價與 speckit 會逐條回溯此清單、核對數量。** 注意「雙地區商品組合」是商業規則（地區別目錄／計價／金流），與「雙語（語言切換）」是兩回事，勿混為一談。

| BR-ID | 商業規則（不變量） | 影響 SCP-ID / 模組 | 最易出錯處 |

| BR-001 | `[條件式／互斥／綁定／地區別／狀態流轉邏輯]` | `SCP-0xx` / `[前台+後台]` | `[邊界或衝突情境]` |
